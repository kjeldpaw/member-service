# member-service

Quarkus service holding the membership register of Wandy Wha Rang, with a Helm
chart in `charts/member-service`. It is deployed on k3s by the k3s repo.

## Agent skills

### Issue tracker

Issues and specs live in this repo's GitHub Issues, managed with `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
